# NTP Projelerim — YMH 219 Nesne Tabanlı Programlama

Bu depo, **YMH 219 Nesne Tabanlı Programlama** dersi kapsamında verilen ek uygulama ödevlerini içerir.
Tüm projeler **C# / .NET / Windows Forms** ile Visual Studio üzerinde geliştirilmiştir.

| # | Proje | Klasör | Kısa Açıklama |
|---|-------|--------|---------------|
| 1 | Not Defteri | [YMH219-NotepadApp](YMH219-NotepadApp) | Dosya işlemleri + JSON serileştirme ile kalıcı not defteri |
| 2 | Flappy Bird Benzeri Oyun | [YMH219-FlappyBird](YMH219-FlappyBird) | Timer, klavye olayları ve çarpışma kontrolü |
| 3 | Key Event Logger | [YMH219-KeyEventLogger](YMH219-KeyEventLogger) | Form içi klavye olaylarını zaman bilgisiyle kaydetme |
| 4 | Chat Uygulaması | [YMH219-ChatApp](YMH219-ChatApp) | TcpListener/TcpClient ile istemci-sunucu sohbet |
| 5 | Speech App | [YMH219-SpeechApp](YMH219-SpeechApp) | Text-to-Speech ve Speech-to-Text |
| 6 | Yüz Tanıma | [YMH219-FaceRecognition](YMH219-FaceRecognition) | OpenCvSharp ile yüz algılama ve LBPH tanıma |

Her proje klasöründe kendi çözüm dosyası (`.sln`), `.gitignore` ve `README.md` dosyası bulunur.

## Genel Gereksinimler

- Windows 10/11
- Visual Studio 2022 / 2026 (".NET masaüstü geliştirme" iş yükü)
- .NET 10 SDK
